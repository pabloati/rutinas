# Rutinas de entrenamiento en casa

Cinco rutinas (Push, Pull y full body A, B, C) con cronómetros, tiempos editables, modo continuo y vídeos.
HTML estático, sin dependencias. Pensado para abrirlo en el móvil mientras entrenas.

Página de inicio: `index.html` (publicada con GitHub Pages en https://pabloati.github.io/rutinas/).

Ver `CLAUDE.md` para el contexto completo del diseño.
